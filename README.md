## 概要
COACHTECH 教材 Tutorial 10-1「認証機能 ハンズオン演習」で作成した成果物です。
Laravel Fortifyを使ったログイン・ログアウト・ユーザー登録機能と、認証が必要なダッシュボードを作成

## 使用技術
- PHP 8.x
- Laravel 10.x
- Laravel Fortify（認証）
- MySQL
  

## 学んだこと
- Laravel Fortify を使ったユーザー登録 / ログイン / ログアウトの仕組み
-auth ミドルウェアでルートを保護する方法
